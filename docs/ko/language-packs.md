## 사용할 언어 선택

관리자로 로그인한 뒤 **관리 → 언어 관리**(`/admin/languages`)를 여세요. 설치된 언어 중 사용자가 선택할 수 있도록 허용할 언어를 활성화하세요. 활성화한 언어 중 하나를 기본 언어로 선택하고 설정을 저장하세요. 최소 한 언어는 활성화해야 합니다. 언어 선택 메뉴에는 각 언어로 표기한 이름이 표시됩니다.

영어와 한국어는 기본 제공 언어입니다. 설정을 한 번도 저장하지 않았다면 `ARTIFACTY_LOCALE=en` 또는 `ko`가 초기 기본 언어를 정합니다. 환경 변수 설정이 없으면 영어를 사용합니다. 관리자가 설정을 저장하면 초기 기본값 대신 저장한 설정을 사용합니다.

브라우저는 직접 지정한 `?lang=<locale>`, 브라우저에 저장된 쿠키, 관리자 기본 언어 순으로 확인하며, 이 중 처음으로 찾은 활성화된 언어를 사용합니다. 비활성화했거나 설치하지 않은 언어는 무시합니다. 활성화된 영어를 직접 선택하면 한국어 쿠키나 기본값보다 우선합니다. `Accept-Language`로 언어를 선택하지 않습니다. 언어 선택 쿠키는 해당 브라우저에 1년간 저장됩니다. 쿠키를 지우면 관리자 기본 언어를 사용합니다. 설정을 저장한 적이 없다면 초기 환경 변수 설정 또는 영어를 사용합니다.

## 사용자 언어 팩 가져오기

1. `/admin/languages/template`에서 JSON 템플릿을 내려받으세요.
2. 새 언어의 `locale`과 `nativeName`을 지정하세요.
3. `messages`의 항목을 번역하세요.
4. `/admin/languages`의 가져오기 입력란에 JSON을 붙여 넣으세요.
5. 언어 팩을 가져오세요.
6. 언어 설정에서 가져온 언어를 활성화하세요.

일부 항목만 번역한 일본어 팩은 다음과 같이 작성할 수 있습니다.

```json
{
  "locale": "ja",
  "nativeName": "日本語",
  "messages": {
    "nav.artifacts": "アーティファクト"
  }
}
```

번역하지 않은 메시지는 영어로 표시합니다. 가져올 때는 현재 등록된 메시지 키만 허용합니다. 번역에는 영어 메시지의 자리표시자 이름을 그대로 유지해야 합니다. 예를 들어 `{count}`를 바꾸면 안 됩니다. 키나 자리표시자가 잘못되면 가져오기를 거부합니다. 애플리케이션 업데이트로 기존 키가 없어지거나 자리표시자가 바뀌면 해당 키의 저장된 번역은 사용하지 않습니다. 대신 현재 버전의 영어 메시지를 표시합니다.

사용자 팩으로 기본 제공 언어인 `en`이나 `ko`를 교체할 수 없습니다. 이미 등록된 사용자 언어의 로케일로 팩을 가져오면 기존 팩을 교체합니다. 사용자 팩은 최대 16개, 팩당 512 KiB, 전체 설정은 4 MiB까지 허용합니다. 크기는 UTF-8 JSON 바이트로 계산합니다. 언어 설정과 팩 메타데이터는 전체 백업에 포함합니다.

언어 팩은 UI 문구를 번역합니다. 명령어, API·MCP 식별자, 저장된 아티팩트 내용은 번역하지 않습니다. [화면 언어 안내](../../README.ko.md#화면-언어)를 참고하세요.
