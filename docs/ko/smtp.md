## 이메일 설정

관리자로 **관리 → 이메일 / SMTP**(`/admin/email`)을 여세요. SMTP 호스트, 포트, 발신자 주소, TLS 방식을 입력하세요. 설정이 준비되면 발송을 활성화하세요. 사용 중인 메일 서비스의 설정을 사용하세요. 이 안내에는 메일 제공업체의 인증 정보를 포함하지 않습니다.

TLS 또는 STARTTLS가 필수입니다. Artifacty는 서버 인증서를 검증하며, 보안 연결에 실패해도 암호화하지 않은 연결로 전환하지 않습니다. 사용자 이름을 비우면 SMTP 인증을 사용하지 않고 저장한 비밀번호도 삭제합니다. 사용자 이름이 있는 상태에서 비밀번호 입력란을 비우면 기존 비밀번호를 유지합니다.

## 사용자 비밀번호 재설정

관리자는 `/admin/users`에서 사용자 비밀번호를 재설정할 수 있습니다. 임시 비밀번호를 생성하고 다음 로그인 때 비밀번호를 변경하도록 합니다. 해당 사용자의 세션은 폐기하지만 기존 API 토큰은 유지합니다.

SMTP 발송을 활성화했다면 임시 비밀번호를 사용자의 이메일 주소로 보냅니다. SMTP 서버가 메시지를 수락해도 받은편지함 도착을 보장하지는 않습니다. 실패하거나 발송 여부가 불확실하면 자동으로 재시도하지 않습니다. 메시지가 이미 수락되었을 수 있기 때문입니다. 관리자 결과 화면에 한 번 표시하는 임시 비밀번호를 직접 전달하세요. 이메일을 다시 보내기 위한 목적으로 비밀번호를 다시 재설정하지 마세요.

## 암호화 키 보호

SMTP 설정 전체를 AES-256-GCM으로 암호화해 SQLite에 저장합니다. 별도 키는 `ARTIFACTY_HOME/secrets/smtp.key`에 있습니다. POSIX 환경에서는 디렉터리 권한이 `700`, 키 파일 권한이 `600`이어야 합니다.

전체 JSON 백업에는 암호화된 설정을 포함하지만 키는 포함하지 않습니다. 업그레이드 스냅샷에도 키를 포함하지 않습니다. 같은 홈에 복원하면 기존 키를 그대로 둡니다. 새 홈으로 이전하거나 복원할 때는 원래 키를 별도로 백업하고 비공개 권한을 유지해 옮기세요.

키를 잃어버리면 암호화된 설정을 복구할 수 없습니다. 설정을 바꾸기 전에 원래 키를 복원하세요. 이전 설정을 복호화하려고 새 키를 생성하지 마세요. 키 백업은 비공개로 보관하고 공유하는 백업 번들과 분리하세요.

저장소 복원 절차는 [업그레이드 스냅샷과 복구](upgrade-backups.md)를 참고하세요.
